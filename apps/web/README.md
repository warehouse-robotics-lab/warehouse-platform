# Web

Пользовательское приложение на Next.js и TypeScript.

Здесь будут страницы, формы, редактор карты и диспетчерская. Приложение использует компонент отрисовки склада из `@warehouse/warehouse-renderer`.

Инициализация приложения выполняется отдельной задачей. Имя workspace-пакета — `@warehouse/web`.
