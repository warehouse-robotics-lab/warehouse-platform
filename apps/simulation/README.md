# Simulation

Серверное приложение на Node.js и TypeScript для исполнения симуляции склада.

Отвечает за запуски, движение роботов и выполнение заданий. Сценарий взаимодействия с API предложен в [ADR-003](../../docs/adr/003-module-interaction.md). Формат команд предстоит согласовать.

Размещение алгоритмов в модуле приложения или отдельном `simulation-core` остаётся открытым решением.

Инициализация приложения выполняется отдельной задачей. Имя workspace-пакета — `@warehouse/simulation`.
