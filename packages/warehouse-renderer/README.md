# Warehouse Renderer

Компонент отрисовки карты, станций, препятствий, роботов и маршрутов для Web.

Выбор Konva/react-konva или PixiJS проводится отдельным исследованием. Компонент получает данные и сообщает о действиях пользователя.

Имя будущего workspace-пакета — `@warehouse/warehouse-renderer`.
