Порядок работы — полный по ADR-002 (согласование — в журнале ниже). Этапов три, каждый
с отдельным человеческим ревью:

на ревью: для тестов — в задаче 2.8, для реализации — в задаче 5.6. Невыполненная
проверка указывается в комментарии прямо.
