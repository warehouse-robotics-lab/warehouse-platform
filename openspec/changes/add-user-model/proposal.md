# Proposal

## Why

Платформе требуются пользователи: аутентификация, роли на складе, приглашения. Прежде чем добавлять модель и миграцию, нужно согласовать данные пользователя и способ входа, чтобы реализация появилась на основе согласованной спецификации. Этот change — только подготовка и согласование спецификации модели пользователя; за ним отдельным change последует реализация.

## What Changes

- Фиксируется способ входа: **email + пароль** (согласовано при подготовке change; подтверждается на ревью спецификации).
- Готовится новая спецификация `user-account` с описанием данных учётной записи:
  - поля пользователя, их назначение и обязательность;
  - уникальность почты и правила её сравнения (нормализация, регистр, пробелы);
  - правила хранения пароля (только хеш);
  - проверяемые случаи: создание пользователя, повторная почта, обязательные значения.
- Спецификация передаётся на человеческое ревью, замечания учитываются, согласование фиксируется.

**Код не меняется.** Подключение Prisma, схема, миграция, тесты и инфраструктура БД — отдельный будущий change, который начнётся после согласования этой спецификации.

## Capabilities

### New Capabilities

- `user-account`: хранение данных учётной записи пользователя — поля, обязательность, правила уникальности и сравнения email, правила хранения пароля, проверяемые случаи создания записи.

## Impact

- **Артефакты OpenSpec**: новый change `add-user-model` (proposal, дельта спецификации, design, tasks).
- **Код**: не затрагивается.
- **Последующие change**: после согласования — реализация модели в `apps/api` (Prisma, миграция, тесты ограничений) по этой спецификации.

## Out of Scope

- Любая реализация: подключение Prisma/БД, схема, миграции, тесты, docker compose.
- Регистрация и вход (эндпоинты, сессии, JWT, выход, восстановление пароля).
- Роли на складе, приглашения пользователей, личный кабинет.
- Привязка Telegram к аккаунту (отложена; спецификация не должна блокировать её добавление).
- OAuth-провайдеры (спецификация не должна блокировать их добавление позже).
