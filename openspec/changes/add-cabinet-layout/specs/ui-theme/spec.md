# Spec Delta

## Purpose

Единое оформление интерфейса Web: светлая тема, семантические цвета и шрифт, значения
которых берутся из согласованного макета `design/warehouse-platform.pen`. Макет —
источник истины для цветов: при изменении макета меняются значения темы.

## ADDED Requirements

### Requirement: Светлая тема

Приложение SHALL отображаться в светлой теме на всех страницах. Тёмная тема MUST NOT
включаться ни по умолчанию, ни по системной настройке пользователя: её значения
в макете не определены.

#### Scenario: Открытие страницы при тёмной системной теме

- **GIVEN** в операционной системе пользователя включена тёмная тема
- **WHEN** пользователь открывает любую страницу приложения
- **THEN** страница отображается в светлой теме: фон `#F8FAFC`, основной текст `#0F172A`

### Requirement: Семантические цвета по макету

Семантические цвета интерфейса SHALL совпадать со значениями переменных макета
(ревизия `7419145`). Цвета, которых нет в макете, остаются прежними.

#### Scenario: Поверхности и текст

- **WHEN** проверяются значения цветов темы
- **THEN** `background` — `#F8FAFC`, `foreground` — `#0F172A`
- **AND** `card` — `#FFFFFF`, `card-foreground` — `#0F172A`
- **AND** `muted` — `#F1F5F9`, `muted-foreground` — `#5E6E85`
- **AND** `accent` — `#F1F5F9`, `accent-foreground` — `#0F172A`

#### Scenario: Акцент, границы и фокус

- **WHEN** проверяются значения цветов темы
- **THEN** `primary` — `#2563EB`, `primary-foreground` — `#FFFFFF`
- **AND** `destructive` — `#DC2626`
- **AND** `border` — `#E2E8F0`, `input` — `#7A8AA0`, `ring` — `#2563EB`

#### Scenario: Цвета навигационной панели

- **WHEN** проверяются значения цветов темы
- **THEN** `sidebar` — `#FFFFFF`, `sidebar-foreground` — `#0F172A`
- **AND** `sidebar-primary` — `#2563EB`, `sidebar-primary-foreground` — `#FFFFFF`
- **AND** `sidebar-accent` — `#F1F5F9`, `sidebar-accent-foreground` — `#0F172A`
- **AND** `sidebar-border` — `#E2E8F0`, `sidebar-ring` — `#2563EB`

#### Scenario: Скругления

- **WHEN** проверяется базовый радиус скругления
- **THEN** он равен 10px; производные радиусы — 8px и 6px, как `radius-md` и `radius-sm` в макете

### Requirement: Шрифт интерфейса

Текст интерфейса SHALL отображаться шрифтом Inter. Русские и английские символы MUST
отображаться одним шрифтом, без подмены кириллицы системным шрифтом.

#### Scenario: Русский текст

- **WHEN** на странице отображается русский текст, например заголовок «Мои склады»
- **THEN** он набран шрифтом Inter
