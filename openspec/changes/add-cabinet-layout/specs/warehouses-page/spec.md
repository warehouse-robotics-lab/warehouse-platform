# Spec Delta

## Purpose

Страница «Мои склады» в личном кабинете: маршрут, заголовок и содержимое страницы.
На текущем этапе страница работает на локальных данных и показывает пустое состояние;
список складов появится отдельными задачами.

## ADDED Requirements

### Requirement: Маршрут страницы

Страница «Мои склады» SHALL открываться по адресу `/warehouses` внутри каркаса кабинета.

#### Scenario: Открытие по адресу

- **WHEN** пользователь открывает `/warehouses`
- **THEN** отображается каркас кабинета, в области содержимого — страница «Мои склады»

### Requirement: Заголовок страницы

Страница SHALL показывать заголовок «Мои склады» как главный заголовок страницы
(первого уровня). Размер — 28px, высота строки — 36px, полужирное начертание.

#### Scenario: Заголовок в двух раскладках

- **WHEN** страница открыта в широкой или узкой раскладке
- **THEN** вверху области содержимого отображается заголовок «Мои склады»
- **AND** вспомогательные технологии определяют его как заголовок первого уровня

### Requirement: Пустое состояние

Под заголовком страница SHALL показывать пустое состояние: заголовок «Здесь пока нет
складов» и пояснение «Когда у вас появятся склады, они будут показаны на этой странице.».
Пустое состояние выводится без карточки и без кнопок и центрируется в свободной области
под заголовком страницы.

#### Scenario: Отображение пустого состояния

- **WHEN** пользователь открывает `/warehouses`
- **THEN** под заголовком страницы по центру свободной области показан текст «Здесь пока нет складов»
- **AND** под ним — пояснение «Когда у вас появятся склады, они будут показаны на этой странице.»
- **AND** кнопки «Создать склад» и других действий нет

### Requirement: Без списка складов

Страница SHALL NOT показывать список, таблицу или строки складов в каком-либо виде
и MUST NOT запрашивать данные о складах. Пустое состояние показывается всегда.

#### Scenario: Содержимое страницы

- **WHEN** пользователь открывает `/warehouses`
- **THEN** на странице есть только заголовок и пустое состояние
- **AND** запросов к API за складами нет

### Requirement: Область содержимого

В широкой раскладке область содержимого SHALL иметь отступы 32px и колонку шириной
не больше 1200px, расстояние между заголовком и пустым состоянием — 24px. В узкой
раскладке — отступы 24px сверху и снизу и 16px по бокам, расстояние — 16px.

#### Scenario: Окно шириной 1440px

- **WHEN** страница открыта в окне шириной 1440px
- **THEN** колонка содержимого занимает 1136px: ширину справа от боковой панели за вычетом отступов 32px

#### Scenario: Сравнение с макетом

- **WHEN** страница открыта в окне шириной 1440px и 390px
- **THEN** заголовок и пустое состояние совпадают с фреймами `Ca1Ii` и `AFo3y` макета `design/warehouse-platform.pen` (ревизия `7419145`) по размерам, отступам, цветам и начертаниям
