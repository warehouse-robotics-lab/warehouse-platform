# Proposal

## Why

Пользователю нужен личный кабинет: общий каркас со шапкой, навигацией и областью
содержимого, а в нём первая страница «Мои склады». Это основа для следующих задач:
списка складов, входа и подключения к API. Задача —
[issue #17](https://github.com/warehouse-robotics-lab/warehouse-platform/issues/17);
дизайн согласован, блокировка по макету снята.

## What Changes

- Приложение переходит на светлую тему. Цвета и шрифт (Inter) берутся из макета:
  макет — источник истины для цветов проекта. Тестовая тёмная тема, включённая
  при инициализации, отключается.
- Добавляется каркас кабинета:
  - шапка с названием продукта «Warehouse Platform» (текст, не ссылка);
  - навигация с одним пунктом «Мои склады»: sidebar фиксированной ширины
    на широком экране, горизонтальная полоса под шапкой на узком;
  - область содержимого.
- Добавляется страница «Мои склады» по маршруту `/warehouses`: заголовок страницы
  и пустое состояние «Здесь пока нет складов».
- Пункт навигации — ссылка. Активный пункт определяется текущим адресом, поэтому
  при появлении новых разделов переключение между ними и «Мои склады» работает
  без доработки пунктов.

Макет: `design/warehouse-platform.pen`, ревизия `7419145`, фреймы `Ca1Ii`
(широкий экран, 1440px) и `AFo3y` (узкий экран, 390px), пустое состояние, светлая тема.

## Capabilities

### New Capabilities

- `ui-theme`: оформление приложения — светлая тема, семантические цвета и шрифт по макету.
- `cabinet-layout`: каркас личного кабинета — шапка, навигация по разделам, область
  содержимого, широкая и узкая раскладки, определение активного раздела по адресу.
- `warehouses-page`: страница «Мои склады» — маршрут, заголовок и содержимое страницы
  (сейчас — пустое состояние).

## Impact

- **Код `apps/web`:**
  - тема и шрифт: `src/app/globals.css`, `src/app/layout.tsx`;
  - новые слои FSD: `src/widgets` (шапка, каркас кабинета), страница в `src/_pages`;
  - маршрут `/warehouses` в `src/app`;
  - компоненты shadcn/ui `sidebar` и `empty` в `src/shared/ui` вместе с их
    зависимостями из реестра shadcn.
- **Другие страницы:** главная `/` и будущий экран входа (#18) тоже становятся
  светлыми с цветами макета. Структура главной страницы не меняется.
- **Зависимости:** новых npm-пакетов не ожидается. Компоненты shadcn копируются
  в проект как исходный код. Изменение `pnpm-lock.yaml` проверяется при установке.
- **Документация:** README `apps/web`, раздел о структуре FSD (новый слой `widgets`).
- **API, авторизация, контракты:** не затрагиваются.

## Out of Scope

- Список и таблица складов в любом виде, фильтры, сортировка, пагинация.
- Кнопка «Создать склад», пункт «Настройки», меню действий над складами.
- Сворачивание sidebar и изменение его ширины. Меню и выдвижная панель на узком экране.
- Тёмная тема. Её значения в макете не нарисованы.
- Авторизация, защита маршрута, переход после входа, подключение к API.
- Изменения главной страницы `/` и переадресация с неё.
- Автоматические тесты: порядок работы по задаче адаптирован, см. `tasks.md`.
