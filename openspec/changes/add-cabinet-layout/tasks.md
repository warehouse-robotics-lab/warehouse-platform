# Tasks

Порядок работы адаптирован относительно ADR-002 для небольшого модуля (согласование —
в журнале ниже). Этапов два:

1. Спецификация — отдельное человеческое ревью.
2. Реализация и проверки — человеческое ревью кода.

Этап согласования тестов не выполняется, автотесты не пишутся. В `apps/web` нет
инструментов тестирования, а поведение сводится к статичной разметке и определению
активного пункта по адресу. Проверка — сборка, typecheck, линтер и ручная проверка
по сценариям спецификаций.

Работа ведётся в одном Draft PR из ветки `feat/web-cabinet-layout`.
