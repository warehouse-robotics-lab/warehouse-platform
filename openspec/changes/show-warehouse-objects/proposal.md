# Proposal

## Why

`packages/warehouse-renderer` уже рисует сетку ([#19](https://github.com/warehouse-robotics-lab/warehouse-platform/issues/19)). [#20](https://github.com/warehouse-robotics-lab/warehouse-platform/issues/20) добавляет объекты и выбор клетки. По [ADR-002](../../../docs/adr/002-ai-development-workflow.md) это поведение нельзя реализовывать, пока нет согласованной спецификации. Режимы ниже — поведение компонента, а не страница-пример.

## What Changes

Редактирование:

- Карта: сетка, препятствия, станции, роботы.
- Клик по клетке и выделение квадрата сообщают Web массив одиночных клеток. Квадрат не возвращается как прямоугольник с шириной и высотой. Одна клетка — массив из одного элемента. Клик вне карты выбор не меняет.
- Смена клетки объекта ставит его на новую клетку сразу, без анимации.

Симуляция:

- Та же карта. Позиция робота — подтверждённая позиция симуляции.
- Во время запуска Web, API и Simulation не передают правку карты. Компонент её не проверяет и не отсеивает клетки. Выбор участка в этом режиме не сообщается. Новый снимок двигает роботов и линию пути.
- Линия будущего пути идёт от этой клетки по переданному `route`. `route` не включает текущую клетку. Пустой `route` линии не даёт. Пакет клетки в линию не добавляет.
- Пока состояния приходят подряд, отметка едет к последней клетке за интервал шага симуляции. Тот же интервал задаёт частоту снимков. Свою длительность пакет не подставляет. Новая клетка заменяет цель.
- При потере промежуточного состояния пропущенные клетки не проигрываются, робот переходит к новому состоянию. Пакет маршрут не достраивает.
- Если в новом состоянии известен текущий отрезок маршрута, анимация идёт только от его начала к новой клетке: видно, откуда она начинается. Если отрезок неизвестен, отметка появляется на новой клетке сразу, без анимации.

## Capabilities

### New Capabilities

- `warehouse-renderer`: карта склада на сетке, выбор участка, мгновенное обновление в редактировании, анимация робота и линия будущего пути в симуляции. Konva остаётся деталью реализации.

### Modified Capabilities

- Нет. `warehouses-page` описывает пустой список складов и это поведение не меняет.

## Impact

- `packages/warehouse-renderer`: props `WarehouseCanvas`, отрисовка объектов, выбор участка, линия будущего пути, анимация позиции симуляции, README пакета.
- `apps/api`, `apps/simulation`, `packages/contracts` не меняются. Контракт снимка остаётся в [#36](https://github.com/warehouse-robotics-lab/warehouse-platform/issues/36).
- Зависимость Konva и react-konva уже есть в пакете ([ADR-004](../../docs/adr/004-warehouse-renderer-konva.md)). Новых библиотек нет.
- Макет объектов карты не передан. Соответствие макету к этому изменению не применяется.
- Согласование спецификации по ADR-002 ещё не получено. Готовность артефактов OpenSpec его не заменяет.
